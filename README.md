# Iron Vein Piercing Check

Norskspråklig MVP for piercingveiledning og strukturert profesjonell vurdering.

## Innhold

- Søkbar kunnskapsbase med 28 vanlige spørsmål
- Egen flyt for navleanatomi og plassering
- Veiledning om tilheling, downsizing, smykker og sikkerhet
- Lokal bildevelger som ikke laster opp bilder
- Generator for strukturert konsultasjonsoppsummering

Åpne `dist/index.html` lokalt for å forhåndsvise siden.

> Faglig veiledning, ikke medisinsk diagnose.
